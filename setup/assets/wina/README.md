# Zdjęcia win (cutouty)

Butelki wycięte z tła (przezroczyste WebP, kanał alpha, płótno 520×1400,
wspólna linia podstawy i jednakowa wysokość). Używane przez slider w sekcji
„Smak Pogórza".

Nazwa pliku odpowiada slugowi wpisu `wino`:

| Plik | Wino |
| --- | --- |
| `bottle-bukowiec.webp` | Bukowiec (Bianka) |
| `bottle-szpilowka-wytrawna.webp` | Szpilówka Wytrawna (Solaris) |
| `bottle-szpilowka-polslodka.webp` | Szpilówka Półsłodka (Solaris) |
| `bottle-rose.webp` | Rosé (Cabernet Cortis) |
| `bottle-marszalek.webp` | Marszałek (Marechal Foch) |

## Jak ustawić

Po `install.sh` wgraj każdy plik do Biblioteki mediów i ustaw jako obraz
wyróżniający odpowiedniego wpisu `wino`. Motyw serwuje WebP bez konwersji do
AVIF, więc przezroczystość jest zachowana. Nie hard-cropuj: rozmiar `bottle`
skaluje proporcjonalnie.
